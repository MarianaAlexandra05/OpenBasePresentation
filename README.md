# Openbase Coder for Windows — Presentation & Landing Page

Una aplicación interactiva y moderna construida en **React** + **Vite**, inspirada en la dirección visual y componentes de **[openbase.cloud](https://openbase.cloud/)**.

---

## ✨ Características Principales

- 🎙️ **Voice Dispatcher Studio**: Simulador interactivo de llamadas de voz y WebRTC LiveKit con visualizador de onda PCM/DirectSound y audio sintetizado.
- 📱 **Simulador iOS iPhone 16 Pro**: Dynamic Island, estado de conexión Win32, transcripción en tiempo real y flujo interactivo de autorización de comandos (Approve / Review / Tests Passed).
- 💻 **PowerShell 7 Windows Terminal**: Consola interactiva con comandos ejecutables (`openbase status`, `openbase doctor`, `pytest`, `openbase units list`).
- ⚡ **Supervisor Win32**: Explorador de unidades JSON en `~/.openbase/windows-units` con monitoreo de procesos detached en segundo plano.
- 🌌 **Hub de Integraciones (Orbit)**: Satélites interactivos para Codex, Claude Code, Cursor, Gemini CLI, VS Code, Warp, PowerShell 7 y GitHub con filtros dinámicos.
- 🩺 **Windows Diagnostics (openbase doctor)**: Suite de auto-diagnóstico en tiempo real con verificación de puertos, binarios nativos, kernel y concurrencia NTFS.
- 🌐 **Bilingüe (Español / Inglés)**: Soporte completo de traducción en tiempo real persistente en localStorage.
- ✨ **Waitlist Modal con Confetti**: Formulario interactivo con feedback visual festivo para acceso temprano.

## 🚀 Cómo probar en Local

### 1. Requisitos
- **Node.js**: v18 o superior
- **npm** o **pnpm**

### 2. Instalación de dependencias
```bash
npm install
```

### 3. Iniciar el Servidor de Desarrollo
```bash
npm run dev
```

Abre tu navegador en:
👉 **`http://localhost:3000`**

### 4. Compilar para Producción
```bash
npm run build
```

## 🛠️ Stack Tecnológico

- **Framework**: React 18 + Vite 6
- **Iconos**: Lucide React
- **Efectos y Animaciones**: Border Beam (`bb-wrap`), Web Audio API, Canvas Confetti
- **Tipografía**: *Geist*, *Geist Mono*, *Instrument Serif* (editorial italic) y *Plus Jakarta Sans*
- **Deploy**: Compatible con Vercel / Netlify / GitHub Pages
